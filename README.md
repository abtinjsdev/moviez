🎬 Moviez

Moviez is a simple and modern movie website where you can discover movies, search for your favorites, and explore different genres.

Features

-🎬 Explore a collection of movies
-  Search for your favorite movies
-  View movie ratings
-  Explore movies by genre
-  Responsive design for different screen sizes
-  Simple and clean user interface

 Built With

- HTML
- CSS
- JavaScript

Getting Started

To get a local copy of Moviez, clone the repository:

git clone https://github.com/abtinjsdev/moviez.git


Then move into the project folder:

cd moviez


You can open the project directly in your browser or use a local development server to run it.
